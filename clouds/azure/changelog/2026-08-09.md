## New / GA
- **Unity AI Gateway on Azure Databricks (GA)** — Centralized governance for AI models, agents, tools, and MCP services: usage monitoring, cost management, guardrails, and access control in one gateway. ([src](https://azure.microsoft.com/updates?id=568910))
  - *Interview angle:* "How do you govern which agents/tools can call which models, with cost caps and guardrails, on Databricks?" — Unity AI Gateway is the new first-party answer.
- **Claude Opus 5 on Azure Databricks (GA)** — Anthropic's latest model, tuned for advanced reasoning, coding, and agentic workflows, added to AI Model Serving. ([src](https://azure.microsoft.com/updates?id=568316))
  - *Interview angle:* Azure's frontier-model catalog (Claude Sonnet 5 GA'd July 2, GPT-5.6 GA'd July 9, now Opus 5) is current within days of each Anthropic/OpenAI release — know the latest, don't cite last quarter's model as "newest."
- **AI Gateway tier in Azure API Management (preview)** — Dedicated APIM tier purpose-built for AI traffic, on top of APIM's existing AI gateway capabilities. ([src](https://azure.microsoft.com/updates?id=568184))
  - *Interview angle:* "Where does AI traffic management live in the Azure stack — APIM or Foundry?" — now both: a dedicated APIM tier plus Foundry-side gateways.
- **Trusted Launch as Default (TLaD) — GA** — Secure Boot and vTPM now enabled automatically on new Gen2 VMs/VMSS instead of opt-in. ([src](https://azure.microsoft.com/updates?id=568600))
  - *Interview angle:* "What's the default security posture of a new Azure VM today?" — Secure Boot + vTPM on by default for Gen2, not something you must remember to enable.
- **Azure Virtual Network routing appliance (GA)** — Managed, specialized-hardware alternative to NVAs for private cross-VNet routing; lower latency/higher throughput than VM-based appliances. ([src](https://azure.microsoft.com/updates?id=568605))
  - *Interview angle:* "How do you route between VNets at scale without deploying and scaling your own NVA fleet?" — a managed routing appliance is now an option.
- **AKS Application Routing with Gateway API (GA)** — Brings the Kubernetes Gateway API standard to AKS ingress, alongside the older Ingress API. ([src](https://azure.microsoft.com/updates?id=567944))
  - *Interview angle:* "Ingress vs Gateway API on AKS — which is production-ready?" — Gateway API-based routing is now GA, not preview-only.
- **Azure Enclave (preview)** — New confidential-computing product streamlining deployment/management of isolated cloud environments for sensitive workloads, across commercial and Government clouds. ([src](https://azure.microsoft.com/updates?id=568377))
  - *Interview angle:* New service name to recognize — don't confuse with existing confidential VMs/confidential containers; Azure Enclave is a higher-level managed wrapper.

## Changed limits & behaviour
- **Azure SQL Database / Managed Instance — 7-day backup immutability by default (GA)** — Immutability now automatically applied to the most recent 7 days of backups for all databases, regardless of configured point-in-time retention. ([src](https://azure.microsoft.com/updates?id=568339))
  - *Interview angle:* "What's Azure SQL's default ransomware/tamper protection on backups?" — 7-day immutability is now on by default, not something you configure.
- **AKS Prepared Image Specification (preview)** — Pre-stages container images and init work on nodes to cut startup latency, aimed at large AI/GPU/Windows node pools. ([src](https://azure.microsoft.com/updates?id=567949))
  - *Interview angle:* "How do you cut node-startup latency for GPU-heavy AKS node pools?" — Prepared Image Specification is the new lever.
- **Azure Key Vault Premium — symmetric keys (preview)** — First native symmetric-key support in Key Vault Premium (oct-HSM key type, AES). ([src](https://azure.microsoft.com/updates?id=566746))
  - *Interview angle:* Previously Key Vault Premium was asymmetric/RSA-EC-centric for HSM-backed keys — symmetric AES support changes what you'd recommend for envelope encryption designs.
- **Azure Monitor Logs mirroring into Microsoft Fabric (preview)** — Log Analytics telemetry now available in OneLake as open Delta Parquet, near-real-time, without duplication. ([src](https://azure.microsoft.com/updates?id=568322))
  - *Interview angle:* "How do you get Azure Monitor log data into a data lake for cross-tool analytics?" — native mirroring into Fabric/OneLake, not an export pipeline you build yourself.

## Deprecated
- **Nested confidential (cc_v5) VM series** — retires September 1, 2026; any unresized affected VM is deallocated on that date. ([src](https://azure.microsoft.com/updates?id=568661))
  - *Interview angle:* If asked about confidential VM series options, cc_v5 nested confidential VMs should not be recommended for new designs — retiring in weeks.
- **Reservation exchanges for savings-plan-covered services** — no longer available starting February 1, 2027 (includes Virtual Machines and other compute reservations). ([src](https://azure.microsoft.com/updates?id=568514))
  - *Interview angle:* "How do you handle changing capacity needs under an Azure Reservation?" — exchanges are going away; commitment strategy needs to shift toward savings plans or careful upfront sizing before Feb 2027.

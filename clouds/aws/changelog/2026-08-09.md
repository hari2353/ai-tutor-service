## New / GA
- **AWS Interconnect — Oracle Cloud Infrastructure (OCI)** — First purpose-built multicloud private-connectivity product reaches GA for OCI: provision resilient, private AWS↔OCI networking without traversing the public internet. ([src](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-price-reduction-of-gpt-models-in-bedrock-cloudwatch-managed-collectors-for-prometheus-metrics-and-more-august-3-2026/))
  - *Interview angle:* "How would you connect AWS and another cloud provider privately, without a VPN over the internet?" — AWS Interconnect is now a first-class managed answer, not just Direct Connect + a partner colo.
- **Amazon CloudWatch managed Prometheus collectors** — Agentless collection of Prometheus metrics from EKS, EC2, ECS, MSK, and OpenSearch Service; no self-managed scrape infrastructure required. ([src](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-price-reduction-of-gpt-models-in-bedrock-cloudwatch-managed-collectors-for-prometheus-metrics-and-more-august-3-2026/))
  - *Interview angle:* "How do you get Prometheus metrics out of an EKS cluster without running your own Prometheus?" — managed collectors are now the default answer, not a self-hosted exporter.
- **Amazon S3 Tables — Variant data type (Iceberg V3)** — Native support for the Iceberg V3 Variant type: semi-structured data (IoT, logs) in a lakehouse table without JSON-blob workarounds. ([src](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-price-reduction-of-gpt-models-in-bedrock-cloudwatch-managed-collectors-for-prometheus-metrics-and-more-august-3-2026/))
  - *Interview angle:* "How do you store schema-flexible payloads in an Iceberg table without falling back to JSON strings?" — Variant is the new native answer.
- **Amazon Bedrock — Claude Opus 5 available** — Anthropic's Claude Opus 5 (stronger agentic-coding and cybersecurity capabilities) added to Bedrock's model catalog. ([src](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-july-27-2026/))
  - *Interview angle:* "What's the newest frontier model available on Bedrock and what's it tuned for?" — Opus 5, agentic coding / cyber use cases.
- **Amazon Bedrock — Web Search (GA)** — Built-in server-side tool grounding OpenAI models (GPT-5.4/5.5/5.6) in live web results with zero data egress from the customer's AWS environment; single API parameter, no external search vendor. ([src](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-bedrock-web/))
  - *Interview angle:* "How do you ground an LLM response in current web knowledge on Bedrock without standing up your own search pipeline?" — Web Search is now a first-party, zero-egress tool.

## Changed limits & behaviour
- **Amazon Bedrock — GPT-5.6 pricing cut** — Effective July 30: GPT-5.6 Luna on-demand pricing down 80% ($0.20/M input, $1.20/M output tokens); GPT-5.6 Terra down 20%. Applies automatically. ([src](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-price-reduction-of-gpt-models-in-bedrock-cloudwatch-managed-collectors-for-prometheus-metrics-and-more-august-3-2026/))
  - *Interview angle:* Any "Bedrock vs self-hosting cost" answer that cites GPT-5.6 pricing from before July 30 is now stale — Luna is one of the cheapest frontier-class models on Bedrock.
- **AWS IAM Identity Center — multi-Region directory replication** — Identity Center directory (not just external-IdP-backed instances) can now replicate to secondary Regions; users keep provisioned entitlements if the primary Region is disrupted. ([src](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-price-reduction-of-gpt-models-in-bedrock-cloudwatch-managed-collectors-for-prometheus-metrics-and-more-august-3-2026/))
  - *Interview angle:* "How do you make SSO resilient to a Region-level IAM Identity Center outage?" — multi-Region directory replication is now available even without an external IdP.
